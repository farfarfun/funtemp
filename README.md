# funtemp

占位包，用于在 PyPI 上保留 `funtemp` 这个包名；具体功能会在之后陆续补充。当前版本提供版本信息，确保包可安装、可导入并可用于基础依赖探测。

## Install

```bash
pip install funtemp
```

## 最小示例

```bash
python -c "import funtemp; print(funtemp.__version__)"
```

预期输出：`0.0.2`。
