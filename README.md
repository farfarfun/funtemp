# funtemp

`funtemp` 是一个提供可导入版本元数据的轻量级 Python 包，当前仅暴露 `__version__` 字段，用于确认包已正确安装。

## Install

```bash
pip install funtemp
```

## 最小示例

```bash
python -c "import funtemp; print(funtemp.__version__)"
```

预期输出：`0.0.2`。
